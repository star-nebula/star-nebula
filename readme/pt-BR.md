## 🧠 Sobre mim

- 🔭 Construindo: um **cofre de memória de IA entre ferramentas** e **gestão de skills para ferramentas de código com IA**
- 🌱 Uma convicção: o próximo gargalo das ferramentas de código com IA não é o modelo — é a **memória** e a **gestão do conhecimento**
- 📝 Ideias e anotações vivem na minha [base de conhecimento / blog](https://star-nebula.github.io/knowledge/)
- 💬 Bate-papo sobre: agentes de IA · Obsidian · sistemas de memória · LLM · fluxos 100% Markdown
- ⚡ Kit diário: Obsidian + um monte de CLIs de IA + Markdown para tudo
