## 🧠 自己紹介

- 🔭 作っているもの：**ツール横断 AI メモリボックス** と **AI コーディング工具のスキル管理** — どの AI CLI も記憶し、探せるように
- 🌱 信条：AI コーディング工具の次のボトルネックはモデルではなく「記憶」と「ナレッジ管理」
- 📝 想法やメモは[ナレッジベース / ブログ](https://star-nebula.github.io/knowledge/)へ
- 💬 話せる話題：AI agents · Obsidian · 記憶システム · LLM · 純 Markdown ワークフロー
- ⚡ 日常装備：Obsidian + たくさんの AI コーディング CLI + すべては Markdown
